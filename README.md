# 🧠 오늘의 기억력 게임 (v2)

메인은 "오늘의 기억력 게임"(5개 카테고리 혼합 5문제), 하단 네비게이션으로 테마별 페이지 이동:
🎬 영화 · 🎤 가수 · 🎭 배우 · 🌍 수도 · 📺 예능 (테마당 하루 5문제)

힌트 버튼 클릭마다 초성 1개 공개, 정답 입력 후 Enter. 날짜 시드로 매일 다른 문제.

## 실행

`index.html` 더블클릭 → 바로 플레이 (내장 샘플 문제).
크롤링 문제(`questions.json`) 반영은 로컬 서버 필요:

```bash
python -m http.server 8000   # → http://localhost:8000
```

## 게임 종류

| 페이지 | 문제 | 정답 |
|---|---|---|
| 영화 | 스틸컷(TMDB) 또는 줄거리·명대사 | 영화 제목 |
| 가수 | 곡명 + 가사 첫 소절 | 가수 이름 |
| 배우 | 뉴스 사진 또는 대표작 설명 | 배우 이름 |
| 수도 | 나라 이름 | 수도 |
| 예능 | 대표 출연진 3인 이상 조합 | 프로그램명 |

점수: 힌트 0개 100점, 초성 열수록 감점(최소 10점). 정답 비교 시 공백·문장부호 무시.

## 난이도

헤더의 😊 쉬움 / 🙂 보통 / 🔥 어려움 버튼으로 선택 (localStorage에 저장, 난이도별로 다른 문제 출제).

난이도 판정 기준 — 주관이 아닌 데이터 지표 사용:

| 카테고리 | 기준 |
|---|---|
| 영화 | TMDB 투표수(vote_count) 상위 1/3 쉬움 / 중간 보통 / 하위 어려움 |
| 가수 | 멜론 차트 순위 1~10위 쉬움 / 11~50위 보통 / 51위~ 어려움 |
| 예능·수도 | 목록에 수동 태그 (지표 없음) |
| 내장 샘플 | 수동 태그 (크롤링 데이터로 대체 권장) |

`difficulty` 태그가 없는 문제는 모든 난이도에서 출제됩니다.

## 연속 출석 & 공유

- 메인(오늘의 게임) 5문제를 완주하면 출석 처리 → 🔥 N일 연속 표시 (브라우저 localStorage 저장)
- 결과 화면에서 "결과 공유하기" → 워들 스타일 이모지(🟩🟥) 텍스트 클립보드 복사
- **IP 기반 출석은 불가**: 정적 HTML은 방문자 IP를 알 수 없고 서버가 필요합니다.
  또한 IP는 유동/공유(회사망·통신사)라서 개인 식별에 부정확합니다.
  확장하려면: ① 지금처럼 localStorage(기기별) ② 간단한 백엔드(Supabase/Firebase 무료 티어) + 익명ID ③ 로그인 순으로 권장.

## 문제 데이터 갱신 (크롤러)

```bash
pip install requests beautifulsoup4
export TMDB_API_KEY=발급받은키     # 영화 스틸컷용(선택), 무료: themoviedb.org/settings/api
python crawler/crawl_questions.py
```

| 카테고리 | 소스 | 비고 |
|---|---|---|
| 배우 | 네이버 연예뉴스 랭킹 (기사 제목 배우명 매칭 + 썸네일) | 실패 시 내장 풀 |
| 가수 | 멜론 차트 TOP100 + 가사 첫 소절 | 실패 시 내장 풀 |
| 예능 | 한국어 위키피디아 API (인포박스 출연자 링크 추출) | 확인 완료, 실패 시 내장 풀 |
| 영화 | TMDB API 스틸컷(backdrop, 제목 안 보이는 이미지) | API 키 필요 |
| 수도 | 내장 데이터 | 크롤링 불필요 |

크론 등록 예 (매일 새벽 5시):

```
0 5 * * * cd /path/to/기억력게임 && TMDB_API_KEY=키 python crawler/crawl_questions.py
```
